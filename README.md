# الماجيكو فى الرياضيات — أ. محمد أحمد

ألعاب تفاعلية لمادة الرياضيات — الصف الأول الإعدادى — الفصل الدراسى الأول.

- `index.html` : الصفحة الرئيسية (الدخول على الفروع الأربعة)
- `numbers.html` / `algebra.html` / `statistics.html` / `geometry.html` : صفحات الفروع والدروس
- `game.html?l=1-1` : ألعاب الدرس (6 ألعاب × 15 سؤالًا، بدون وقت محدد)
- `data/` : أسئلة كل درس (ملف لكل درس)
- `images/` : صور الأسئلة المقتطعة من الكتاب
- `assets/` : التصميم ومحرك الألعاب (يعمل بدون إنترنت عدا الخط)

للنشر على GitHub Pages: ارفع محتويات المجلد كما هى ثم فعّل Pages من الإعدادات على الفرع الرئيسى.
